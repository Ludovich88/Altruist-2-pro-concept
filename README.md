# Altruist-2 Pro — концепт-проект

Многопараметрический монитор качества воздуха для городских исследований.

> **Статус:** концептуальное проектирование (v0.x). Документы узлов — рабочие черновики,
> факты и цены помечены датой проверки и источником.

## Общий образ устройства

**Философия:** «двойная верификация и самокалибровка». На одной плате стоят
PM-сенсоры двух разных производителей — расхождение их показаний служит
аппаратным индикатором достоверности данных, а не багом.

| Аспект | Решение (цель) |
|---|---|
| Назначение | распределённый городской мониторинг воздуха |
| PM2.5/PM10 | два параллельных канала разных производителей |
| Газы | CO/NO₂ (MOX) + O₃ + SO₂ (электрохимия; SO₂ — слот rev A, см. ADR-001) |
| Проводная связь | полноценный Ethernet + PoE-питание |
| Беспроводная | LoRa / Meshtastic + Wi-Fi/BLE для конфигурации |
| Корпус | ASA, IP54, УФ-стойкость, наружное размещение |
| BOM | < €220 (цена устройства ~€440) |
| Запуск | Kickstarter Q1–Q2 2027 |

## Как читать документы узлов

Каждый узел содержит:
- `README.md` — постановка вопроса, критерии выбора, требования смежных узлов;
- `trade-study.md` — таблица вариантов с сильными/слабыми сторонами, ценами и
  ссылками на документацию; в конце — черновая рекомендация.

## Ключевые решения и артефакты (2026-10-06)

- **Газовый блок:** MiCS-4514 (CO+NO₂, £9.90 RS) + SPEC 110-406 (O₃, $20) + SGP41 ($6.12) ≈ $38–40.
- **SO₂ в ревизии A** (ADR-001, decisions/): SPEC SO₂-HS 110-641 ($25 Mouser); слот DNP в City-конфигурации,
  запаян в индустриальной SO2-CFG; канал LMP91000 разведён сразу. NO-интерференции нет (у 110-641),
  городской фон ниже LOD — канал для эпизодов и промзон.
- **Обвязки сенсоров** задокументированы в каждом узле: LMP91000 на электрохимию (O₃/SO₂),
  PWM-нагрев+прецизионный делитель для MOX (MiCS-4514), цифровым сенсорам — питание/UART/I²C/механика.
- **Datasheets скачаны локально** (18 PDF + текстовые выжимки): `02-pm-sensors/datasheets/`,
  `03-gas-sensors/datasheets/`, `07-env-sensors/datasheets/`. Ссылки на локальный файл + исходный URL — в документах узлов.
- **Экологические условия сенсоров** (T/RH по даташитам) — SPEC-v0.2 §3.2; итоговый диапазон устройства
  −10…+50 °C / 15–90 %RH non-condensing (узкие места: SDS011 и электрохимия).
- **Методика измерений** — SPEC-v0.2 §3.3 (прогрев, компенсации, T90, O₃-NO₂ коррекция, SO₂-LOD дисклеймер, калибровка, хранение).
- ТЗ актуально: `spec/SPEC-v0.2.md` (v0.1 — архив).
