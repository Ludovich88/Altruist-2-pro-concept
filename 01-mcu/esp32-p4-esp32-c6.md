# Вариант: ESP32-P4 + ESP32-C6 (двухчиповая связка)

*Файл-приложение к [trade-study.md](trade-study.md). Проверено поиском 2026-10-07.*

## Описание варианта

Главная плата строится на **ESP32-P4** — флагманском высокопроизводительном SoC Espressif
без радиотракта, к которому по **SDIO** подключается **ESP32-C6** в роли Wi-Fi/BLE-модема
(официальные стеки `esp_wifi_remote` / ESP-Hosted-MCU). Проводной Ethernet — родной EMAC
P4 через внешний RMII-PHY (IP101G/LAN8720), PoE — стандартный PD-фронтенд.

Это **отработанный промышленный путь**: Espressif выпускает референс-платы
(ESP32-P4-Function-EV-Board, Waveshare ESP32-P4-WIFI6-POE-ETH — уже с PoE-модулем),
драйвер сопроцессора входит в состав ESP-IDF официально.

## Ключевые характеристики

| Критерий | Значение |
| --- | --- |
| CPU P4 | 2×RISC-V HP @400 МГц (6.92 CoreMark/MHz) + LP-core 40 МГц |
| SRAM / PSRAM | 768 КБ HP + 32 КБ LP; 16 или 32 МБ PSRAM в корпусе (QFN104 10×10) |
| GPIO | 55 |
| Ethernet | ✅ EMAC RMII на кристалле P4 |
| Радио | через C6: Wi-Fi 6 (2.4 ГГц), BT 5 (LE), 802.15.4 (Zigbee/Thread) |
| ADC | ✅ SAR ADC на P4: 2 блока — ADC1 8 кан. (GPIO16–23), ADC2 6 кан. (GPIO49–54) |
| USB | USB 2.0 High-Speed OTG + Full-Speed OTG |
| Цена (реф.) | P4 ~$3.06 (sample); C6 чип $2.03@1 → ~$1.69@1k (LCSC C5364646); C6-WROOM-1-N8 ~528 шт в стоке LCSC |
| Прошивки | две: приложение на P4 + модемная на C6 |

## Сильные стороны

1. **Максимальная вычислительная мощность из трёх вариантов**: 400 МГц dual-core
   с запасом под слияние 4 сенсоров + edge-AI калибровку (AdaBoost) + web-интерфейс.
2. **Связка проверена индустрией и вендором**: `esp_wifi_remote`/ESP-Hosted —
   официальная поддержка в IDF; готовые референсы с Ethernet+PoE (Waveshare
   ESP32-P4-WIFI6-POE-ETH) сокращают риск разводки.
3. **Модем C6 — зрелый и дешёвый**: чип в стоке у LCSC/JLC/Mouser (~$1.7–2.0 @1k),
   модули в наличии; поставки C6 стабильны с 2023–2024.
4. **SAR ADC на борту P4** (14 каналов) — прямые аналоговые входы сохраняются для
   резервных каналов (NTC трубы подогрева, контрольные точки) без внешнего ADC.
5. **802.15.4 в комплекте** (на C6) — задел под Thread/Zigbee-интеграции, не требуемый
   ТЗ, но бесплатный в BOM.
6. **LP-core P4**: энергонезависимый сценарий «сон с пониженным потреблением» на
   будущее (не критично при PoE-питании, но есть архитектурно).
7. **Обновляемость модема отдельно от приложения**: C6 живёт своей прошивкой —
   Wi-Fi-стек можно обновлять независимо от основного приложения.

## Слабые стороны

1. **Два чипа, две прошивки, два кристалла на плате**: сложнее производство,
   отладка (нужен второй JTAG/UART-порт или прошивка модема через SDIO-бутлоадер),
   +2–3 прослеживаемых компонента BOM.
2. **SDIO-мост**: разводка 4-битной SDIO с согласованием, домены питания,
   контроль сброса сопроцессора — типовое, но требующее аккуратности.
3. **Datasheet P4 всё ещё PRELIM (v0.7)** — возможны ECO по железу.
4. **Официальный Arduino framework P4 не поддерживает** (только ESP-IDF;
   у Meshtastic/ESPHome путь — через pioarduino/IDF).
5. **Wi-Fi только 2.4 ГГц** — в плотной городской застройке диапазон зашумлён.

## Риски и возможные проблемы

| Риск | Вероятность | Последствия | Митигация |
| --- | --- | --- | --- |
| Зрелость esp_wifi_remote/ESP-Hosted (падения Wi-Fi при загрузке шины) | низкая-средняя | отладочные дни, репутационные баги в поле | референс Waveshare как основа; стресс-тест SDIO на EV-плате до ревизии A |
| Supply P4 (новый чип, выборзка) | средняя (снижается к 2027) | сдвиг производства | фиксировать дистрибьютора к ADR-002; Kickstarter-таймлайн Q1–Q2 2027 благоприятен |
| Двухчиповая сборка (bga/SDIO) на контрактном производстве | низкая | +1–2 % брака монтажа | QFN — не BGA, стандартная техника; DFM-прогон |
| Meshtastic-порт | средняя | нет готового варианта; BLE/Wi-Fi Meshtastic через прокси esp_hosted — адаптация | оценить объём работ до ADR-002; fallback — mesh только по LoRa, без Wi-Fi-фич |
| Ранние партии P4 = инженерные сэмплы 360 МГц (лимит) | низкая | производительность −10 % | проверять дата-код/маркировку при закупке |
| PRELIM-даташит: ECO по питанию/IO | низкая-средняя | переразводка ревизии | следить за обновлениями до фиксации ревизии A |

## Вывод для Altruist-2 Pro

**Безопасный зрелый дефолт с максимальной производительностью.** Все технические
проблемы известны и закрыты референсами; главный хвост — Meshtastic-адаптация и
двухпрошивочная модель сопровождения. Цена связки чипами ~$4.7–5.1, модулями ~$6–7.
