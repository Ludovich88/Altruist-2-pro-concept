# Вариант: ESP32-S31 (одночиповое решение)

*Файл-приложение к [trade-study.md](trade-study.md). Проверено поиском 2026-10-07.*

## Описание варианта

**ESP32-S31** — новый флагман Espressif «всё в одном»: dual-core RISC-V @320 МГц
с **интегрированными и проводным, и беспроводным коннективити** — Ethernet MAC
(до 1 Гбит/с, RMII/RGMII + внешний PHY), Wi-Fi 6 (2.4 ГГц), Bluetooth 5.4
(LE **+ Classic BR/EDR**), 802.15.4 (Thread/Zigbee). Никакого SDIO-моста, никакой
второй прошивки: одна платформа, один образ firmware, одна цепочка производства.

По классу это «S3-преемник с Ethernet»: та же одночиповая простота разработки,
что у привычного S3, но с проводным Ethernet и современным радио.

## Ключевые характеристики

| Критерий | Значение |
| --- | --- |
| CPU | 2×RISC-V @320 МГц (6.86 CoreMark/MHz), один core с 128-бит SIMD-путём |
| SRAM / PSRAM | 512 КБ SRAM; PSRAM DDR 250 МГц 8-бит, одновременный доступ flash+PSRAM; модули до 16 МБ |
| GPIO | 60–62 |
| Ethernet | ✅ GMAC 100 Мбит (RMII) / 1 Гбит (RGMII), внешний PHY |
| Радио | ✅ на кристалле: Wi-Fi 6 2.4 ГГц, BT 5.4 LE + Classic, 802.15.4 |
| ADC | ✅ 2 блока SAR ADC, 8 каналов (DAC нет) |
| USB | Native USB 2.0 OTG + USB Serial/JTAG |
| Прочее | 4 UART + 1 lite, 3 SPI, 2+1 I²C, TWAI (CAN), DVP-камера, RGB-LCD, JPEG-кодек, 14 touch-каналов |
| IDF | ESP-IDF 6.1+ (самая свежая ветка) |
| Цена (реф.) | ~$3.8 (sample, страница Espressif); массовое производство с 27.07.2026 |
| Прошивки | одна |

## Сильные стороны

1. **Один чип закрывает всё ТЗ**: Ethernet + Wi-Fi + BLE + (бесплатно) Thread/Zigbee.
   Нет SDIO-моста, нет второй прошивки, нет сопроцессорной отладки — модель
   сопровождения проще всех вариантов: один образ, один OTA-контур.
2. **Нет точки отказа «мост»**: на P4-связках падение SDIO/Wi-Fi-модема роняет
   коннективити; здесь радио и приложение — одно домено отказа, штатные
   IDF-механизмы перезапуска стека отработаны годами.
3. **SIMD + 320 МГц dual-core** — заявлен производителем под edge-AI/NN-инференс:
   прямой запас под слияние сенсоров и AdaBoost-калибровку.
4. **BT Classic (BR/EDR)** — единственный вариант из трёх с классическим Bluetooth:
   совместимость со старыми BLE-хостами не нужна, но SPP-профили и legacy-аудио
   закрываемы (у C6/C5 — только LE).
5. **GMAC с запасом ×10**: 1 Гбит/с RMII/RGMII — для устройства достаточно 100M
   RMII-PHY (9 пинов, дёшево), но гигабит остаётся опцией без смены MCU.
6. **8 аналоговых каналов + 62 GPIO + USB HS + CAN** — резервы под будущие
   ревизии картриджа и слоты датчиков без расширителей.
7. **Массовое производство уже идёт** (27.07.2026) — это не инженерные сэмплы,
   а серийный чип с публичным прайсом.

## Слабые стороны

1. **Самая молодая экосистема из трёх**: сообщество, библиотеки, ответы на
   StackOverflow, референс-дизайны — беднее, чем у S3/P4; datasheet до недавнего
   PRELIM, отельные разделы могут уточняться.
2. **Требует ESP-IDF 6.1+** — самая свежая ветка SDK; ранние версии традиционно
   несут регрессии. **Arduino-путь закрыт до выхода arduino-esp32 4.0**
   (ожидается 11/2026) — это блокер и для Meshtastic-порта.
3. **Meshtastic-порт не существует** (открытый issue meshtastic/firmware#10981
   «[SOC]: Add support for ESP32-S31», заблокирован на Arduino 4.0). При таймлайне
   Kickstarter Q1–Q2 2027 порт теоретически успевает, но это чужой график.
4. **Модули S31 у западных дистрибьюторов (Mouser/DigiKey/LCSC) — наличие не
   подтверждено**; чип серийный, но модульная линейка и сток требуют проверки
   перед фиксацией решения.
5. **Wi-Fi только 2.4 ГГц** — нет dual-band (в отличие от P4+C5).
6. **Single source**: новый кремний Espressif в первый год — классические риски
   ранних ECO и неравномерных поставок.

## Риски и возможные проблемы

| Риск | Вероятность | Последствия | Митигация |
| --- | --- | --- | --- |
| Молодость IDF 6.1 (регрессии Wi-Fi/Ethernet-стеков) | средняя | отладка SDK-уровня, сдвиги | пилотный прогон всех драйверов на EV-плате до ADR-002; багрепорты в Espressif (они заинтересованы в ранних кейсах) |
| Meshtastic-порт (Arduino 4.0 11/2026 → затем порт) | средняя | нет mesh-функции к старту кампании | опция: Meshtastic только как LoRa-гейт по UART (см. 06-wireless), MCU не зависит; либо ждать port |
| Наличие S31-модулей у дистрибьюторов | средняя | задержка прототипов | проверить Mouser/DigiKey/LCSC до ADR-002; dev-старт на EV-плате Espressif |
| Ранний кремний: ECO/stepping-баги | низкая-средняя | переразводка ревизии | следить за errata до фиксации rev A; Kickstarter-таймлайн Q1–Q2 2027 даёт ~6 мес дозревания |
| Бедность сообщества (готовых решений меньше) | высокая | больше своего кода | бюджетировать +2–4 нед инженерии против P4-варианта |
| Отсутствие DAC | нулевая | — | в устройстве DAC не требуется (MCP4728 — внешний I²C на картридже) |

## Вывод для Altruist-2 Pro

**Архитектурно самое чистое решение: один чип = один firmware-контур = самая простая
эксплуатация и сопровождение.** Технических компромиссов против ТЗ нет. Цена вопроса —
зрелость: SDK 6.1 и Arduino 4.0 только выходят, Meshtastic-порт в очереди, модули у
дистрибьюторов не подтверждены. Если к моменту ADR-002 (фиксация MCU) эти три пункта
закроются — S31 становится фаворитом; если нет — безопасный путь P4+C6.
