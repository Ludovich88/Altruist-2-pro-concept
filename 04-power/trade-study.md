# 04 — Питание (PoE PD + DC-DC)

## Постановка вопроса

приёма питания по Ethernet (IEEE 802.3af/at) + резервный DC-вход. Бюджет
потребления по ТЗ ~2.4 Вт (расчёт для полной нагрузки) — Class 0 (до 12.95 Вт)
даёт четырёхкратный запас на расширение.

## Критерии выбора

1. Стандарт: 802.3af (12.95 Вт) достаточно; at — запас, но дороже.
2. Изоляция: нужна ли 3 kV (совместная работа с USB-отладкой, внешними датчиками)?
3. КПД DC-DC от 48 В (или 12 В промежуточной шины) до 5/3.3 В.
4. MPS (Maintenance Power Signature) — чтобы PSE не отключал устройство в простое.
5. Защиты: surge, overcurrent, обратная полярность DC-входа.

## Архитектура (черновик)

```
RJ45 (данные + PoE) → magnetics → PD-контроллер (TPS2375) → первичный DC-DC 48→5В
                                   → (опция) изоляция → шина 5В
ш 5В → 3.3В LDO/buck (MCU, сенсоры) + 5В для MOX-нагревателя и SDS011
DC-резерв: барьерный диод OR / ideal-diode контроллер
```

- Внимание: при 24В-PoE-инфраструктуре проверить совместимость конкретного PD.
- MPS-резистор обязателен.
- Резервный DC: 5–12 В вход через ideal-diode (LM66100-class или P-MOSFET схема).

## Открытые вопросы

1. Изолированный или неизолированный PoE? (изоляция +$3–5 и трансформатор DC-DC)
2. Разъём резервного DC (barrel 5.5/2.1? USB-C?) и диапазон входного напряжения.
3. Нужен ли суперконденсатор/батарейка RTC для сохранения времени при переключении питания?
