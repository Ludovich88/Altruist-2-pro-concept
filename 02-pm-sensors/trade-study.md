# 02 — PM-сенсоры (двойная верификация)

## Постановка вопроса

Ядро философии продукта: **два PM-сенсора разных производителей** на одной плате.
Расхождение показаний = индикатор достоверности (высокая влажность >40% RH резко
повышает погрешность лазерных сенсоров — это надо детектировать, а не прятать).

## Критерии выбора

1. Разные оптические/аэродинамические конструкции (максимум некоррелированной ошибки).
2. UART-выход (безопасный цифровой интерфейс, 2 отдельных порта).
3. Наличие/цена, доступность в 2026–2027.
4. Потребление (SDS011 содержит вентилятор).
5. Отклик и стабильность в полевых исследованиях (литература).

## Детали по компонентам базы ТЗ

### Nova SDS011 (канал A)
- Диапазон 0–1000 µg/m³, разрешение 0.3 µm, отклик ~1 с, UART.
- Требует **вентилятор** (шум, износ, ~90 мА) — нужен сервисный интервал.
- **Условия работы (datasheet V1.3):** −10…+50 °C, RH ≤70 % (хранение: −20…+60 °C, ≤90 %); давление 86–110 кПа; питание 4.7–5.3 В, >1 Вт, ripple <20 мВ.
- Datasheet: **локально** [`datasheets/SDS011_datasheet_V1.3.pdf`](datasheets/SDS011_datasheet_V1.3.pdf) (оригинал: https://cdn-reichelt.de/documents/datenblatt/X200/SDS011-DATASHEET.pdf)
- Цена ~€24 (Tinytronics, в наличии, 2026-10): https://www.tinytronics.nl/en/sensors/air/dust/nova-sds011-high-precision-laser-dust-sensor

### Plantower PMSA003 (канал B)
- Диапазон 0–500 (max 1000) µg/m³, 38×35×12 мм, UART, 3.3 В, без вентилятора (пассивный забор).
- **Условия работы (datasheet):** −10…+60 °C, RH 0–99 % (без конденсации); хранение −40…+80 °C; 5 В (4.5–5.5), ≤100 мА, standby ≤2 мА; MTTF ≥3 года.
- Datasheet: **локально** [`datasheets/PMSA003_datasheet.pdf`](datasheets/PMSA003_datasheet.pdf) (зеркало: https://lemariva.com/storage/app/media/uploaded-files/PMSA003.pdf)
- Цена ~£26.5 с адаптером (PiHut): https://thepihut.com/products/pmsa003-particulate-matter-sensor-with-adapter-board

## Обвязки PM-канала

PM-сенсоры цифровые (UART) — AFE типа LMP91000 не требуется; обвязка электрическая и механическая:

1. **Питание**: у SDS011 вентилятор+лазер >1 Вт с пусковым током — отдельный DC-DC (не-shared с аналоговой частью), конденсатор 470 µF у разъёма, ripple <20 мВ. PMSA003 — отдельный LDO 5 В (≤100 мА).
2. **UART**: 2 аппаратных порта (9600 8N1, TTL 3.3 В); SDS011 TX/RX — 3.3 В уровни штатно; защита TVS на кабельных линиях (снаружи корпуса).
3. **Механика/воздух**: разнос впусков >10 см (см. раздел ниже), виброразвязка вентилятора SDS011 (резиновые стойки — шум не передаётся корпусу), вертикальная ориентация SDS011 по recommended installation direction.
4. **Конденсат**: подогрев впускной камеры (управление по T/RH от узла 07) — RH >70 % убивает SDS011-камеру.
5. **Обслуживание**: лазер SDS011 8000 ч ресурса → при 24/7 нужна циклическая работа (30 с из каждой минуты продлевает жизнь ~2×, см. Tinytronics примечание) и сервисный интервал ~12 мес.

## Аппаратные требования из ТЗ (переносятся в 08-enclosure/)

- Раздельные UART для обоих сенсоров.
- Расстояние впусков **> 10 см** (SDS011-вентилятор не должен тянуть воздух мимо PMSA003).
- Подогрев впуска против конденсата в оптической камере.
- PTFE-мембрана на путях газовых сенсоров (см. 03/08), PM-впуск — открытое окно с дождевым зонтом.

### Выводы из сравнительных исследований (верификация)

- **Heliyon/PMC10176080 (2023)**: SPS30 vs PMS5003 × 8 шт, 12 мес коллоукация с Fidas 200S.
  SPS30 стабильно точнее на 2-мин разрешении (расширенная неопр. медиана 50 % против
  125 % у PMS5003); после калибровки RLM по числу частиц + RH — оба достигают reference-grade.
- **PM между-сенсоры (= между экземплярами одного продукта) мал:** SPS30 ~1.1 µg,
  PMS5003 ~1.2 µg — значит «два разных производителя» действительно добавляют
  независимую ошибку, что и поддерживает двойную верификацию нашего проекта.
- **egusphere-2026-2537 (Эфиопия, indoor+outdoor):** SPS30 slope 1.19–1.23 к гравиметрии
  (систематически занижает ~17–23 %), SEN55 slope 1.11; SPS30↔SEN55 — не взаимозаменяемы
  подстановкой, ratio 0.92–0.93. Итог: SPS30 НЕ эталон, требует локальной калибровки.

### Резюме для пары (двойная верификация)

1. **Базовый, дешёвый:** SDS011 + PMSA003 ≈ €52 — сохраняем как канал A+B. Дешёво, проверено, redundанс вендоров.
2. **Буст доверия:** SDS011 (канал A) + SPS30 (канал B, +$30 BOM против PMSA003). Плюс:
   индустриальный класс, MCERTS, drift ≤1.25 µg/год, 4 фракции PM. Минус: оба лазерные
   (Sensirion использует другой алгоритм + sheath air), SPS30 дороже в ~2 раза.
3. **Single-chip альтернатива:** SEN65 заменяет PM-канал + частично 07-env (T/RH), но
   разрушает концепт «два независимых сенсора» и слишком новая (премьера Q3-2025,
   полевых данных ещё нет) — **не рекомендуется** для запуска в 2027.

## Высоко-сводный выбор пары

- **Рекомендация:** канал A = SDS011 (€24, канал «народного» мониторинга), канал B = SPS30
  ($40–50, MCERTS-класс). Компактность PMSA003 не критична для Pro-версии, уровень
  доверия SPS30 оправдывает +$30 BOM. Но — этот шаг подтягивает BOM над €220,
  финализировать только вместе с 10-bom.
