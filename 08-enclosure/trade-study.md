# 08 — Корпус, механика, газовые пути

## Постановка вопроса

Наружный корпус ASA (IP54, УФ-стойкость) с продуманной аэродинамикой: PM-впуск
(активный SDS011 + пассивный PMSA003) физически разнесён с газовыми сенсорами,
чтобы нагрев MOX и вентилятор не искажали показания друг друга.

## Критерии выбора

1. УФ/климатическая стойкость (ASA), стабильность цвета на солнце.
2. IP54: дождь/брызги при сохранении свободного воздухообмена — основная сложность.
3. Разделение воздушных потоков: PM-A, PM-B, газы, электроника (4 зоны).
4. Термоизоляция электроники от солнечного нагрева (чёрный ASA на солнце > +20°C к окружке).
5. Технология: FDM-прототип → литьё/роспуск к Kickstarter (цены на литьё).

## Требования из ТЗ (перенос из обсуждения)

- Впуски PM-A (SDS011, вентилятор) и PM-B (PMSA003): **расстояние > 10 см**.
- Подогрев впуска: резистор у входа PM-каналов против конденсата (PWM от T-сенсора).
- Газовые сенсоры: собственный диффузионный отсек с **PTFE-мембраной**
  (защита от пыли/капель; MiCS-4514 боится силиконов/растворителей — фильтр обязателен).
- PMSA003 — пассивный диффузионный, SDS011 — активный забор: не размещать вход
  PMSA003 в струе вентилятора SDS011.
- Отверстие дренажа снизу (конденсат), glands для кабелей: RJ45 (PoE), DC-резерв,
  SMA-антенна LoRa, (опц.) солнечный резерв.

## Компоновка (черновик)

```
┌────────────────────────────────────────┐
│  [SMA LoRa]        [RJ45+PoE]  [DC]    │  ← нижняя зона разъёмов (герметичные glands)
│                                        │
│  ┌──────────┐      ┌──────────┐        │
│  │ PM-A вход│      │ PM-B вход│        │  ← боковые стенки, расстояние >10 см,
│  │ (SDS011) │      │(PMSA003) │        │    дождевые козырьки, подогрев
│  └──────────┘      └──────────┘        │
│                                        │
│  [газовый отсек: PTFE-мембрана]        │  ← отдельная камера, пассивная диффузия
│                                        │
│  [плата: MCU, PoE, AFE]  [SHT4x]       │  ← электроника, термически развязана
│  [дренаж ↓]                            │
└────────────────────────────────────────┘
```

## Термоуправление

- Светлый/белый пигмент ASA или отражающее покрытие (чёрный + солнце = перегрев).
- Радиатор на buck-конвертере PoE (2.4–4 Вт потерь при КПД 80%).
- Точка: сенсоры калиброваны на 23°C — нагрев корпуса смещает показания →
  внутренний SHT4x + ПО-компенсация (см. 09).

## Открытые вопросы

1. Аэродинамика: CFD-модель или эмпирика на прототипе? (выдув SDS011 не должен
   рециркулировать в PMSA003)
2. Сертификация IP54: собственные испытания vs аутсорс (бюджет Kickstarter).
3. Подогрев впуска: резистивная плёнка у входа или нагрев всей PM-камеры?

*Цены ориентировочные; уточнить при выборе подрядчика.*
