# Дизайн: подготовка воздуха для PM-сенсоров (каналы A/B)

## 1. Физика: почему подогрев входа обязателен

Три независимых источника сходятся:

| Факт | Число | Источник |
|---|---|---|
| SDS011 без осушки | завышение 24ч-средних **до ×38** vs гравиметрия при высокой RH | Duisburg 2-летний тест, AAQR 2023 |
| SDS011 с осушкой | максимум **×5.4**, зависимость от RH почти исчезает | тот же |
| Остаточное смещение | постоянное **×≈2.5 вниз** — калибруется одним коэффициентом | тот же (Table 3: 2.51/2.59) |
| SVOC-потеря | нагрев >~40 °C испаряет полетучую (SVOC) фракцию → занижение PM2.5 | Nature Sci. Rep. 2025 |

Механизм — **гигроскопичный рост частиц**: растворимые соли (сульфаты, нитраты, NaCl)
при RH выше точки deliquescence/эффлоресценции (70–80 %) впитывают воду и растут в диаметре;
оптический сенсор видит выросшие частицы → завышение массы. Классика: 3× при 50 %RH →
9.5× при 94 %RH.

**Ключевой нюанс:** нагрев НЕ осушает воздух (абсолютная влажность постоянна), он
«сушит частицы» — RH падает только пока воздух горячий. Если воздух остывает до
входа в сенсор, RH возвращается и частицы снова «напиваются». Отсюда два жёстких
конструктивных требования:

1. Сенсор сидит **вплотную** к нагретой зоне;
2. Тракт на подходе к сенсорам должен быть **тёплым** (труба изолирована, вход сенсора
   в тёплом объёме корпуса).

## 2. Расчёты: формулы и происхождение каждой цифры (запускаются скриптом calculations.py)

**Формулы всех пяти разделов собраны здесь; каждое число в таблице можно
воспроизвести, запустив `python3 calculations.py`.**

### 2.1 Как складывается длина трубки (формула residence time)

Определяющее требование — не геометрия, а **физика высыхания частиц**: по
(Nature Sci. Rep. 2025) аэрозольная частица с водяной плёнкой полностью
высыхает за **≥ 1 секунду** в воздушном потоке. Отсюда длина нагретой секции:

```
поток          Q  = 1 LPM = 1·10⁻³ м³ ÷ 60 с = 1.667·10⁻⁵ м³/с   (даташит SDS011 V1.3: fan 0.3–1.2 LPM)
площадь сечения A  = π·(d/2)²  ; d = ID трубы
скорость        v  = Q / A
время пребывания τ  = L / v = L·A / Q = L·π·d²/4 / Q         →  τ ≥ 1 с  =>  L ≥ 4·Q / (π·d²)
```

Для **ACR 3/8"** (OD 9.52 мм): стенка тонкостенная 0.8 мм → **ID = 7.9 мм**:

```
v = 1.667e-5 / (π·(0.0079/2)²) = 0.34 м/с (34 см/с)
L(τ=1 с) = 4·1.667e-5 / (π·0.0079²) = 0.34 м  →  берём 40 см, τ = 1.18 с (запас 18 %)
```

| Длина нагретой секции | τ | вердикт |
|---|---|---|
| 25 см | 0.74 с | мало |
| 30 см | 0.88 с | мало |
| 35 см | 1.03 с | минимально |
| **40 см** | **1.18 с** | **принято (запас на изгибы/дроссель)** |

Эквивалент в форме «змеевик»: 40 см трубы ÷ (π·Ø_спирали) витков →
при Ø спирали 9 см это **~2.5 витка ≈ компактный цилиндр высотой ~6 см**.
Резерв: толстостенная ACR (wall 1.47 мм → ID 6.58 мм) НЕ проходит — τ = 0.82 с
даже при 40 см (v = 0.49 м/с — сечение меньше, скорость выше).

### 2.2 Мощность нагревателя: два слагаемых (формулы)

Нагреватель греет **воздух** (a) и компенсирует **теплопотери через изоляцию**
(c) — других слагаемых в установившемся режиме нет: стенку (тонкостенная медь,
теплоёмкость мизерная и прогрев транзиентный < 1 мин) и продувание пренебрегаем.
Считаем по частям.

**(a) Нагрев самого воздуха** (объёмная теплоёмкость):

```
массовый расход   ṁ  = ρ·Q = 1.2 кг/м³ · 1.667e-5 м³/с = 2.0·10⁻² г/с
мощность на поток P_возд = ṁ·c_p·ΔT ;  c_p(воздух) = 1006 J/(кг·К)
                       = 20 мВт/K · ΔT
ΔT = +15 K      → 0.30 Вт      (это только нагрев ВОЗДУХА — малая доля)
```

**(b) Психрометрия: на сколько кельвинов греем?** Формула Магнуса-Бака
(давление насыщенного водяного пара):

```
e_s(T) = 6.1121 · exp(b·T / (c+T))  [гПа]
  (b,c) = (17.62, 243.12) при T ≥ 0 °C; (22.46, 272.62) при T < 0 °C
парциальное давление воды (постоянно при нагреве!) p_v = RH·e_s(T_наружа)
RH после нагрева до T_цель: RH(вход сенсора) = 100·p_v / e_s(T_цель)
```

Требование: RH ≤ 45–50 % на входе. Отсюда ΔT для каждого сценария:

| Наружа | ΔT (из психрометрии) | RH на входе | P_возд (ΔT·20 мВт/К) |
|---|---|---|---|
| 20 °C / 90 % | +10 К | 50 % | 0.20 Вт |
| 20 °C / 95 % | +13 К | 45 % | 0.26 Вт |
| 0 °C / 95 % | +15 К | 34 % | 0.30 Вт |
| −10 °C / 90 % | +15 К | 27 % | 0.30 Вт |
| −20 °C / 80 % | +15 К | 21 % | 0.30 Вт |
| 30 °C / 95 % | +10 К | 55 % | 0.20 Вт |
| 35 °C / 85 % | +12 К | 45 % | 0.24 Вт |

Итого на воздух: **максимум 0.30 Вт** — микроскопическая доля.

**(c) Теплопотери через изоляцию — главный потребитель.** Стационарная
1D-модель (цилиндрическими эффектами при d≫t_изол пренебрегаем; площадь —
по **ID**: тепло сопротивляется на границе воздух–стенка):

```
Q_потеря = A·ΔT_total / R_total
A        = π·d_ID·L  = π·0.0079·0.40 = 0.00995 м²   (внутренняя поверхность трубы)
R_total  = t_изол/k_изол + 1/h_out     (последовательные сопротивления)
k_изол   = 0.04 W/(м·К)   (EPDM/NBR HVAC-пена)
h_out    = 5 + 4·v_ветер  W/(м²·К)     (штиль: 5; ветер 5 м/с: 25)
ΔT_total = T_стенки − T_окружения      (худший случай 45 K: 65 °C нити при −20 °C)
```

Для ACR 3/8" L = 40 см, ΔT = 45 K:

| Конфигурация | R_total (м²·К/Вт) | Потери |
|---|---|---|
| Штиль + 5 мм EPDM | 0.125 + 0.2 = 0.325 | **1.38 Вт** |
| Ветер 5 м/с + 5 мм | 0.125 + 0.04 = 0.165 | **2.71 Вт** |
| Ветер 5 м/с, без изоляции | 0.04 | **11.20 Вт** — неприемлемо |

*Сверка: wind=5 м/с + изоляция: 45 K · 0.00995 м² / 0.165 = 2.71 Вт — совпадает
с выводом calculations.py [3].*

**(d) Итог по мощности нагревателя** (суммируем worst-case):

```
P_нагревателя ≥ P_возд + Q_потеря = 0.30 + 2.71 ≈ 3.0 Вт   →  дизайн-бюджет 3.0 Вт
Запас даёт (i) изоляция реально хуже в мокром снегу, (ii) NTC-гистерезис
съедает часть цикла, (iii) мощность PI-плёнки при ±5 % tolerance.
Дежурный режим (OFF летом) : 0 Вт — управляемый ON/OFF.
```

### 2.3 Проверка размера PI-плёнки (JLCPCB custom)

Плёнка обёрнута вокруг трубы 9.52 мм OD — рабочая полоса **12 мм × 400 мм**
(40 см нагретой секции + запас на концы):

```
Площадь          S  = 40 см · 1.2 см = 48 см²    (одна сторона)
Плотность мощности q = P/S = 3 Вт / 48 см² = 0.0625 Вт/см²
                 (типовой предел PI ~2.5 Вт/см² → запас ~40×)
Цена вопроса     R = U²/P = 25/3 = 8.33 Ом;  I = P/U = 0.60 А
                 MOSFET AO3400A (5.7 А) — запас ~9×; затвор управляется напрямую с GPIO
```

Лимит по спецификации PI-нагревателей (типовая длительная плотность
2.5–3 Вт/см², кратковременно выше): **запас ≈ 40×** — деградация плёнки
исключена. Для справки: JLCPCB указывает длительную температуру плёнки до
150 °C (кратковременно 200 °C), наш дизайн ≤ 65 °C на нити.

**Сопротивление дорожек** (повтор §2.3 выше — здесь исходный расчёт):

```
R = U²/P = 5² / 3 = 8.33 Ω     (JLCPCB: tolerance ±5 % при R ≥ 1 Ω)
I = P/U = 0.6 A                (MOSFET AO3400A: 5.7 A max — запас 9×)
```

Кроссовер (двухслойность) JLCPCB не поддерживает — трассировка плёнки —
одиночный змеевик 30–50 µm фольги; фабрика делает её бесплатно по параметрам
(напряжение, мощность, L×W).

### 2.4 Residence time — сводка (главный расчёт, детали в §2.1)

**Верно повторить:** нагретая секция = 40 см (змеевик ~2.5 витка Ø 9 см,
τ = 1.18 с ≥ 1 с); далее **холодный хвост** 5–8 см без изоляции — к входам
сенсоров воздух приходит при ~40 °C (верхняя грань SVOC-потерь).

### 2.5 Пассивный путь (когда нагрев не нужен)

Когда корпус прогрет солнцем до 45 °C, наружный воздух 20 °C/90 % в камере даёт
RH = **22 %** — нагрев не нужен вовсе. Нагреватель реально нужен в холодный/дождливый
период (утро/ночь/зима). Отсюда: **ON/OFF-логика по RH**, а не всегда-он.

## 3. Варианты конструкции

> **Решение (2026-10-09): нагреватель = плёночный полиимидный (PI/Kapton),
> вариант B — принят как основной.** Заказ — JLCPCB Flexible Heaters (custom:
> 5 В / 3 Вт / 12×400 мм / R 8.3 Ω / опция NTC в плёнке). Варианты A и C
> оставлены как documented fallback (прототип-отладка управления без риска
> сжечь единственный плёночный образец).

### Вариант B — ПЛЁНОЧНЫЙ (ВЫБРАН): PI/Kapton heater + MCU ON/OFF

**Polyimide (Kapton) film heater 5 В/3 Вт**, обёрнут вокруг трубы, питание через
MOSFET + ON/OFF от brain board; управление гистерезисом по RH от SHT40 + NTC на
трубе. Компоновка и все формулы — в разделе 2.3 и на схеме
[kapton-heater-design.svg](kapton-heater-design.svg).

- Расчёт: R = U²/P = 8.33 Ω, I = 0.6 А; площадь полосы 40 см × 1.2 см = 48 см² →
  плотность q = 3/48 = **0.0625 Вт/см²** (типовой предел PI ~2.5 Вт/см² → запас
  ~40×); плёнка −40…+150 °C длительно, дизайн ≤ 65 °C.
- JLCPCB custom: фабрика бесплатно трассирует змеевик по заданию (U, P, L×W),
  min размер 10×10 мм, допуск R ±5 % (≥1 Ω), NTC-площадка встроенная.
- Идеальный thermal contact прямо на медь (клей-слой PSA) — минимум потерь.
- Полный контроль: ON/OFF/долгий PWM, dynamic target (RH 45–55 %), телеметрия.
- Защита: MOSFET-отказ «stuck on» → внешний NTC-страж (T > 50 °C > 5 мин →
  разрыв цепи + телеметрия FAIL). Абсолютный fail-safe уровня PTC-нити даёт
  термопредохранитель thermal fuse 66 °C последовательно с плёнкой (~$0.1).

BOM: Kapton custom (JLCPCB) ~$1–2 + MOSFET ~$0.15 + NTC ~$0.1 + thermal fuse
66 °C ~$0.1 ≈ **$2–3** (дешевле вариантов A и C, при полном контроле).

### Вариант A — Server-класс (Duisburg-стиль): PTC-нить без электроники (fallback)

Саморегулирующаяся нагревательная нить (self-regulating heating cable, 12 В),
внешним источником DC-DC boost 5→12 В.

- PTC-нить сама ограничивает температуру ~65 °C (сопротивление растёт → мощность падает).
  Контроллер не нужен вообще. Fail-safe по физике: обрыв ПО → перегрев невозможен.
- В Duisburg такой юнит работал **2 года 24/7 без единого сбоя**.
- Минусы: boost 5→12 В ($1.5–2); постоянное потребление 1–3 Вт даже летом.

BOM: трубка ~$2 + PTC-кабель ~$4 + изоляция ~$1 + NTC + DC-DC ≈ **$8–10**.

### Вариант C — Гибрид: PTC-нить + MCU ON/OFF поверх (третья альтернатива)

Физический предел от PTC-нити (65 °C, fail-safe) + brain board решает:
1. ON/OFF по RH-гистерезису от SHT40: вкл ≥65 %RH, выкл ≤60 %RH;
2. NTC-страж: T>50 °C дольше 2 с → отключение + телеметрия FAIL;
3. Duty-cycle для энергии;
4. Телеметрия: T_трубы, RH_in, state heater (OFF/HYST/FAIL).

BOM: вариант A + MOSFET (AO3400 ~$0.15) + 1×GPIO + NTC ≈ **$9–11**.

**Итог:** вариант B напрямую дешевле, контролируемее и надёжнее, а требуемая
«самоограниченность» решается копеечным thermal fuse 66 °C: при отказе управления
плёнка греется дальше, но предохранитель последовательно рвёт цепь при 66 °C —
заброс выше невозможен, fail-safe тот же, что у PTC-нити.

## 4. Управление: нужен ли MCU?

- **A (нет MCU):** работает, но нагрев всегда-он → жрёт PoE-бюджет постоянными 1–3 Вт
  и не отключается летом; для Kickstarter-продукта с PoE 12.95 Вт — прожиточно, но расточительно.
- **B (полный MCU):** избыточно — PID-регулировать самоконтролируемый нагреватель
  бессмысленно.
- **Рекомендация:** управление нужно, но минимальное — **ON/OFF гистерезис** +
  NTC-страж. Выполняется тем же ESP32-P4 из проекта — **отдельный MCU не нужен**.
- На плате появляется: 1×GPIO → MOSFET → нить; 1×ADC → NTC 10k.

## 5. Ловушки (в обязательном порядке учитываются)

1. **Холодная труба = конденсация.** Если труба холодная (наружа), пар конденсируется
   внутри неё. Труба изолируется снаружи, но не от теплоты нити. Проверка при приёме:
   внутри трубы влага не собирается.
2. **Утеплитель дышит.** EPDM-пена впитывает воду на год-два → деградация изоляции.
   Альтернатива: фторопластовая лента (PTFE ribbon) поверх нити + герметик.
3. **SHT40 только upstream.** SHT40 ставится ДО нагревателя (мерит родной наружный
   воздух). Встроенные SHT40/T-датчики PM-модулей врут из-за самонагрева и lag ~30 мин.
4. **65 °C слишком горячо для сенсора.** Между концом нагретой секции и входом
   сенсора — **5–8 см «холодной зоны»** (без нити, без изоляции) → труба отдаёт
   несколько K до входа, на входе ~40 °C (верхняя грань до SVOC-потерь).
5. **Изоляция горячей части** — иначе ветер 5 м/с съедает 3 Вт впустую.
6. **Канал B (0.1 LPM)** берёт долю через тройник + дроссель — не мешает потоку A.

## 6. Схема тракта

См. [tract-scheme.svg](tract-scheme.svg) (общая) и
[kapton-heater-design.svg](kapton-heater-design.svg) (узел нагревателя).
Логика движения снизу вверх:

```
вход (screen от дождя/насекомых), уклон вниз от головы
   |
[drip leg — капельник, дренаж вниз + screen от насекомых]
   |
[ACR copper 3/8" тонкостенная (OD 9.52 / ID 7.9 мм), вертикальный змеевик Ø9 см, 2.5 витка = нагретая секция 40 см]
[PI (Kapton) плёнка 12 мм × 400 мм, 5 В / 3 Вт / R 8.3 Ω, wrap по спирали]   <- 1×GPIO → MOSFET → 5 В
[thermal fuse 66 °C последовательно + NTC: в плёнке или на стенке]
[изоляция EPDM/NBR ID 13 мм × 5 мм (K-Flex ST / Fermap)]
   |
[5–8 см «холодная зона» без изоляции → ~40 °C на входе]
   |
[вход SDS011 (канал A)] [вход PMSA003 (канал B, тройник+дроссель)]
   |
[внутри корпуса: SHT40 upstream (до нагревателя, мерит наружный воздух)]
```

## 7. firmware: телеметрия и защита нагревателя

- Телеметрия: T_трубы (NTC в плёнке), RH_in (SHT40), state heater (OFF/HYST/FAIL).
- Счётчик наработки нагревателя (интеграл duty-cycle) — предиктивная замена.
- Калибровка PM: ×2.5 фактор как константа в firmware config.

## 8. Конденсат в тракте

Конденсация **в нагретой секции невозможна** (самая горячая точка; вода испаряется).
Два источника и один выход:

1. **Брызги дождя**, прорвавшиеся screen в холодной голове (до нагрева) — стекают
   вниз, если трасса без горизонтальных полок.
2. **Ночная конденсация в стоящей трубе** (зимой стенка холодная, воздух из корпуса
   диффундирует внутрь).
3. **Отказ нагревателя на морозе** при высокой абсолютной влажности → воздух может
   охладиться до росы где-то в тракте.

**Вывод (дизайн-шаблон):**
- трасса от головы до нагретой секции — **непрерывный уклон вниз**, без полок;
- **drip leg** (капельник) в нижней точке: открытый снизу, защищён screen'ом от
  насекомых; капли собираются и испаряются от подогретого воздуха;
- вертикальный змеевик работает самотёком — капля стекает по виткам вниз;
- опционально: датчик WET/DRY (два контакта в drip leg, ~$0.1) → телеметрия.
