# 11 — Air preparation (подготовка воздуха для PM-сенсоров)

Узел-дизайн тракта подготовки аспирационного воздуха перед входом в PM-сенсоры
(SDS011 канал A + PMSA003 канал B): подогрев входа против конденсата и гигроскопичного
роста частиц, управление нагревом, компоненты, расчёты.

**Статус:** черновик (2026-10-09). Зафиксировано частично в ADR-002
(декларация «PTC-подогрев ~65 °C + SHT40 upstream»); этот узел — инженерная проработка.

## Коротко (TL;DR)

- Нагрев входа — **обязателен**: без осушки SDS011 завышает 24ч-средние до ×38 при высокой RH
  (Duisburg 2-летний тест); с подогревом ≤×5.4, зависимость от RH почти исчезает.
- Нужная мощность мала: **3 Вт покрывает худший случай** (ветер, изоляция 5 мм, ΔT 45 K)
  при потоке 1 LPM. Нагрев самого воздуха ≈ 20 мВт/K → 0.2–0.3 Вт на ΔT 10–15 K.
  **Откуда 3 Вт:** P = ṁ·c_p·ΔT (воздух) + Q_потеря (изоляция) = 0.30 + 2.71 Вт —
  все формулы и подстановка в design.md §2.2.
- Откуда длина 40 см: τ = L·π·d²/4/Q ≥ 1 с (высыхание частиц, Nature 2025) →
  при ID 7.9 мм и потоке 1 LPM: L ≥ 34 см → берём 40 см (τ = 1.18 с). Формулы в design.md §2.1.
- Цель — **RH ~45–50 % на входе в сенсор**, не «посуше» (выше ~40 °C начинается потеря
  SVOC-фракции → занижение PM2.5).
- **Нагреватель — ВЫБРАН: плёночный полиимидный (PI/Kapton), вариант B** — custom через
  JLCPCB Flexible Heaters: 5 В / 3 Вт / полоса 12×400 мм / R = 8.33 Ω (±5 %) / 0.6 А,
  плотность 0.63 Вт/см² (запас 4–5×), опция NTC прямо в плёнке, thermal fuse 66 °C как
  абсолютный fail-safe. Прототип ~$1–2, серийно $0.5 @1k. PTC-нить (вариант A) — fallback.
- Труба: медная **ACR 3/8"** (OD 9.52 мм → ID 7.9 мм) × **40 см** нагретой секции
  (residence time 1.18 с > 1 с, требование Nature 2025); геометрия — вертикальный
  змеевик (см. variants.md, 4 варианта с картинками), drip leg для конденсата,
  изоляция HVAC под 3/8", «холодная зона» 5–8 см между нагревом и входом сенсора.
- Остаточное смещение после осушки (~×2.5 вниз) — постоянное, переносится одним
  калибровочным коэффициентом.
