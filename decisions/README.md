## Шаблон ADR

```
# ADR-NNN: <заголовок>
- Статус: предложено / принято / отклонено / заменено ADR-XXX
- Дата:
- Контекст:
- Решение:
- Аргументы за / против:
- Последствия (BOM, ТЗ, firmware, калибровка):
- Альтернативы, отклонённые:
```
