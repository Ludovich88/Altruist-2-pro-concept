# ADR-002: Аспирационная архитектура сенсорного тракта — картридж газов + подогрев входа PM

- **Статус:** принято (2026-10-09, по решению пользователя)
- **Контекст:** газовый тракт — самый шумочувствительный в устройстве (токи ячеек 10–50 нА/ппм,
  сигналы микровольтовые); PM-оптика гибнет от конденсата при RH >70 % (SDS011 ≤70 %RH work),
  а без осушки SDS011 завышает 24ч-средние до 38× против гравиметрии при высокой RH
  (2-летний полевой тест, Duisburg: с подогревом входа ≤5.4×). Гигроскопичный рост частиц:
  3× при 50 %RH → 9.5× при 94 %RH — заявленный диапазон 15–90 %RH прямо в зоне риска.
- **Решение:**
  1. **Картридж газов ↔ brain board:** ячейки (SPEC 110-406, слот 110-641, MiCS-4514, SGP41)
     + 2×LMP91000 + обвязка MiCS + свой T/RH — на отдельной PCB-картридж. Наружу только
     **I²C + питание (8 pin)**; AFE вплотную к ячейке, аналоговые сигнальные тракты не
     покидают картридж.
  2. **PM-вход:** входная труба (Cu/латунь, ~25 см × ~9 мм) с **саморегулирующейся
     нагревательной нитью PTC (self-limiting ~65 °C)** — без контроллера и MOSFET,
     fail-safe по физике (проверено в Duisburg: 2 года без сбоя). Мощность ~0.3 Вт
     рабочая (1 LPM, ΔT 15 K), резерв 2–5 Вт duty-cycled — в PoE Class 0 бюджет влезает.
  3. **Цель по RH на входе ~50 %, не «посуше»:** греем только до RH ≈ 50 %. Перегрев выше
     ~40 °C на входе в сенсор испаряет SVOC-фракцию → систематическое занижение PM2.5.
  4. **Управление:** гистерезис по RH «вкл. при ≥65–70 %» (выше порога — включено, ниже
     с запасом −5 % — выключено). SHT40 стоит **на входе, до нагревателя** (внутренний
     T PM-модулей врёт из-за самонагрева и реагирует ~30 мин); плюс NTC на трубу как
     overtemp-страж (~$0.1).
  5. **Газы: подогрев НЕ нужен** — общий «тёплый плениум» (общий прогретый объём);
     трасса NH₃ — короткая, чтобы не пересушить.
- **Аргументы за:**
  - Расходники отдельно от электроники: картридж = замена за 2 минуты без пайки
    (электрохимия и MOX — единственные узлы, которые стареют).
  - Конфигурации = BOM-опция: одна brain board + разные картриджи → City / SO2-CFG / Ref-CFG.
  - Spare footprints на картридже: новый газ (NH₃, NO, H₂S) = сенсор в свободное место.
  - Kickstarter-практика: potting/герметизация отдельно, 2 малых PCB проще в рефлоу/ремонте.
  - Защита PM-камеры от конденсата + стабильная калибровка PM (осушка не отменяет
    калибровку — делает её стабильной и переносимой одним коэффициентом).
- **Цена:** +$3–6 BOM (коннектор, вторая PCB, сборка); коннектор — новая точка отказа
  (лечится gold-plated castellated или board-to-board). City ≈ $127 → ~$130–133 итог.
- **Альтернативы, отклонённые:**
  - Аналоговые сигналы по кабелю к главной плате — наводки от Wi-Fi/ETH-радио и DC-DC
    рушат микровольтовые тракты.
  - Активный контроллер подогрева вместо PTC-нити — лишние детали/точки отказа;
    self-limiting нить проще и fail-safe по физике.
  - Осушка до RH < 50 % — потеря SVOC-фракции, занижение PM2.5 против гравиметрии.
  - «Самый дешёвый» T/RH (китайские $0.5-аналоги, CHT8305 и т.п. — ±4–5 %RH против
    SHT40 ±1.8 %RH); точность этого сенсора умножается на всё устройство
    (управляет нагревом + компенсация газов). SHT40 ~$1.3 @1k — уже в узле 07.
  - T внутри PM-модуля как управляющий — врёт из-за самонагрева, задержка ~30 мин.
- **Последствия:**
  - Плата: коннектор I²C 8 pin на brain board; посадочный размер картриджа.
  - Механика: входная труба в корпусе (узел 08), уплотнение трассы, NTC.
  - Firmware: драйвер гистерезиса RH PTC-нагревателя; чтение SHT40 upstream + NTC.
  - Калибровка PM: смещение (factor ~2.5 вниз после осушки в Duisburg) — переносится
    одним коэффициентом, фиксируется в калибровочной кампании (SPEC §6).
- **Ссылки:** Duisburg 2-летний полевой тест SDS011 + PTC-впуск; расчёт по Магнусу
  (вход 0 °C / 95 %RH → RH_out ~34 % при ΔT 15 K; худший случай 90 % @ −10 °C → 21 %).
