# ТЗ v0.2 — Altruist-2 Pro

> v0.2 (2026-10-06): добавлены SO₂-канал (rev A), обвязки AFE, экологические характеристики сенсоров,
> методика измерений, ADR-001.

## 1. Назначение

Городской многопараметрический монитор качества воздуха: PM2.5/PM10/PM1, газы (CO, NO₂, O₃, SO₂),
VOC/NOx-индексы, микроклимат (T/RH/P). Дистрибутированная сеть (Meshtastic/Ethernet), Kickstarter Q1–Q2 2027.

## 2. Измеряемые параметры

| Параметр | Сенсор | Канал | Приоритет |
|---|---|---|---|
| PM1 / PM2.5 / PM10 | SDS011 + PMSA003 (двойная верификация) | лазерное рассеяние | P0 (ядро ценности) |
| CO | MiCS-4514, элемент A | MOX | P1 |
| NO₂ | MiCS-4514, элемент B | MOX | P0 (ВОЗ 10 µg/m³) |

## 3. Требования к газовому тракту

### 3.1 Аппаратура (rev A платы)

- **O₃, SO₂ (электрохимия SPEC)**: индивидуальный LMP91000 на каждый канал (потеностат + TIA),
  I²C 0x48–0x4B через A0/A1, Vref от общего референса, C_f по чувствительности ячейки.
  SO₂-слот: посадочное место SO₂-HS + канал LMP91000 **разведены в rev A, сенсор DNP** (конфигурация SO2-CFG).
- **MiCS-4514 (MOX)**: LMP91000 не применим. Схема: делитель (R_load прецизионный 0.1%),
  расчёт Rs/R0 по datasheet, PWM-нагрев с обратной связью (MCP4728 → компаратор/ADC → MOSFET),
  прогрев ≥60 с перед опросом, контроль целостности нагревателя.
- **SGP41**: I²C 0x59, без внешней обвязки, hotplate управляется командами Sensirion.
- Питание аналоговой части: отдельный LDO, общий референс для Vref AFE.

### 3.2 Экологические условия сенсоров (из даташитов, 2026-10-06)

| Сенсор | Рабочая T | Рабочая RH | Примечание |
|---|---|---|---|
| MiCS-4514 | −30…+85 °C | 5–95 % (non-cond.) | MOX требует прогрева, T-компенсация по SHT40 |
| SPEC 110-406 (O₃) | −30…+50 °C | 15–90 % (non-cond.) | электрохимия: RH<15 % → осушение электролита |
| SPEC SO₂-HS 110-641 | −30…+50 °C | 15–90 % (non-cond.) | аналогично |
| SGP41 | −10…+85 °C | — (5–95 тип.) | валидация в диапазоне T 15–35 °C |
| SDS011 | −10…+50 °C | ≤70 % (work) / ≤90 % storage | PM: конденсат недопустим; хранение −20…+60 °C |
| PMSA003 | −10…+60 °C | 0–99 % (non-cond.) | |
| SHT40 | −40…+125 °C | 0–100 % | |
| BMP390 | −40…+85 °C | — | |

**Пересечение для спецификации устройства**: рабочий диапазон монитора задаёт узкое место PM-канал
(−10…+50 °C) и электрохимия (15–90 % RH) → **ТЗ: −10…+50 °C, 15–90 % RH non-condensing**.

### 3.3 Методика измерений (примечание в ТЗ и в инструкции)

1. **Прогрев**: MOX (MiCS-4514, SGP41) — 60 с минимум, лучше 5–10 мин до выхода на стабильный Rs;
   электрохимия — после длительного хранения 24 ч стабилизации; в работе — постоянная поляризация (LMP91000 держит bias).
2. **Компенсация**: все газовые каналы нормируются по T/RH (SHT40) — коэффициенты из даташитов + полевая калибровка.
3. **Периодичность**: MOX опрос не чаще 1 Гц (нагрев стабильнее), электрохимия — усреднение 60 с (T90 у SPEC 60–120 с, у Alphasense ≤45 с).
4. **O₃ = OX − NO₂-компонента**: у SPEC 110-406 нет встроенной NO₂-компенсации; при росте NO₂ (трафический эпизод) O₃-канал завышается → используем SGP41 NOx-index и MiCS-4514 NO₂ как компенсирующие входы ML-модели.
5. **SO₂: дисклеймер LOD**: городской фон ~0.2–1.1 ppb ниже разрешения (<10 ppb rev-HS); канал предназначен для эпизодов >20–30 ppb и индустриальных зон. NO-интерференции нет (0 при 10 ppm NO), NO₂-кросс −1.82 мал.
6. **Калибровка**: поле — co-location с референсной станцией 2–4 недели на партию; MOX R0 — по чистому воздуху; электрохимия — span-gas раз в 6–12 мес (для индустриальной конфигурации).
7. **Хранение/транспорт**: электрохимия — в упаковке, короткозамкнутые выводы (SPEC поставляет на плате-держателе с замыканием), <25 °C; не хранить при RH <15 %.

## 4. Архитектура

- MCU: ESP32-S3 (v1) → развилка P4/S31 (узел 01, отдельный ADR при выборе).
- Сеть: Ethernet W5500 (SPI) + LoRa Meshtastic (узел 06) + Wi-Fi.
- Питание: PoE 802.3af/at Class 0; бюджет ~2.4–4.3 Вт (запас ≥3×).
- Корпус: ASA IP54, узел 08.

## 5. Конфигурации (вариативная сборка)

| Конфигурация | Газовый набор | Целевой рынок |
|---|---|---|
| City (v1 базовая) | 4514 + O₃ + SGP41 | города EU/US |
| SO2-CFG (индустриальная) | + SO₂-HS 110-641 (запаян) | промзоны, порты, угольные регионы, Global South |
| Ref-CFG (референс-опция) | + Alphasense-тройка | лаборатории, пилоты с муниципалитетами |

## 6. Критерии приёмки

1. PM-канал: корреляция r² ≥ 0.85 с референсом (co-location 2–4 недели).
2. NO₂: после ML-компенсации ±20–50 % (заявляем как «тренды и события», не референс).
3. O₃: суточный цикл противофазен NO₂ (отпечаток «трафик/фотохимия») — проверяется на пилоте.
4. SO₂ (SO2-CFG): детекция эпизода ≥50 ppb (проверка span-gas), фон не читается — заявляем честно.
5. Uptime ≥ 30 дней (watchdog), телеметрия 1 мин, буфер ≥ 7 дней при потере связи.

## 8. Открытые вопросы

1. Quote Amphenol SGX (MiCS-4514): 100/1k/10k — single point of supply.
2. Quote SPEC/Interlink: 110-406 + 110-641 (100/1k), статус платформы после переезда сайта.
3. EOL-статус LMP91000 (TI) — проверить, при риске закладывать совместимую замену.
4. MCU-развилка S3 vs P4 — отдельное решение (узел 01) — не блокирует rev A газового тракта.
5. Meshtastic-порт на выбранную MCU (для S3 подтверждён; для P4/S31 — нет).
