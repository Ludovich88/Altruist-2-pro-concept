# Техническое задание — черновик v0.1

> Черновик концепт-фазы (июнь 2026) + правки после требования «полноценный Ethernet
> через PoE». Формулировки требований будут фиксироваться по мере закрытия решений по узлам.

## 1. Обзор

Altruist-2 Pro — многопараметрический монитор качества воздуха для городских
исследователей. Ключевая философия — **двойная верификация и самокалибровка**:
два PM-сенсора разных производителей на одной PCB дают аппаратную перекрёстную
проверку и компенсацию погрешностей. Наружное размещение, PoE-питание,
mesh-сеть Meshtastic, BOM < €220.

## 2. Функциональные требования

| # | Требование | Техническое описание | Приоритет |
|---|---|---|---|
| F1 | Измерение PM | Параллельный двухканальный сбор PM2.5/PM10 (разные производители) | P0 |
| F2 | Измерение газов | CO/NO₂ (MOX) + O₃ (электрохим.) — три канала | P0 |
| F3 | Слияние данных | Оценка достоверности по разнице двух PM-каналов, калибровка | P0 |
| F4 | Активный отбор проб | Подогрев впуска (конденсат) + охлаждение платы | P1 |
| F5 | Проводная связь | Полноценный Ethernet (не SPI-limited) | P0 |
| F6 | Питание | PoE IEEE 802.3af/at + резерв DC | P0 |
| F7 | Беспроводная связь | LoRa (стек Meshtastic) + Wi-Fi/BLE конфигурация | P0 |
| F8 | Корпус | ASA, IP54, УФ-стойкость | P1 |
| F9 | Расширение | Резервные I²C/UART | P2 |

## 3. Ключевые ограничения

- Рабочий диапазон: **−10…+50 °C**, городская уличная установка.
- ЭМС: подавление помех при совместной работе множества сенсоров.
- BOM: **< €220** (~50% от розничной цены ~€440).
- Непрерывная работа 24/7 без обслуживания ≥ 12 мес.

## 4. Архитектура (черновик, следует за выбором MCU)

- Ядро: см. `01-mcu/` — кандидат по умолчанию после смены требований: чип/связка
  с аппаратным Ethernet MAC (RMII или RGMII).
- Сенсоры: 2× UART (PM), 1× ADC-мультиплексирование (газы), 1× I²C (T/RH), LoRa SPI.
- Питание: PoE PD → 5 V → 3.3 V; бюджет ~2.4–3 Вт по расчёту ТЗ.

## 5. Не решено (открытые вопросы)

1. MCU: S31 (новинка, 1 чип) vs P4+C5 (зрелость, 2 чипа) vs S3+W5500 (компромисс) — `01-mcu/`.
2. MOX-сенсор CO/NO₂: MiCS-4514 под риском доступности (SparkFun retired) — `03-gas-sensors/`.
3. Частотный план LoRa под целевые регионы (868/915 МГц) — `06-wireless/`.
4. Механика газовых путей и разделение впусков — `08-enclosure/`.
